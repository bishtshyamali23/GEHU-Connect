# GEHU Connect 🎓

### A University Student Portal

GEHU Connect is a university student portal project inspired by Graphic Era Hill University (GEHU). It brings academic information and student resources together through a unified interface.

The project combines web development with Data Structures and Algorithms (DSA) to demonstrate practical software engineering concepts.

## ✨ Features

* 📢 **Notice Board:** Organizes academic notices, fee updates, exam announcements, and events.
* 🔎 **Trie-Based Search:** Supports prefix-based searching through notice titles.
* 📚 **Recent Notices:** Uses a Stack to track recently viewed notices.
* 📅 **Attendance:** Provides access to attendance-related information.
* 📝 **Assignments:** Organizes assignment information.
* 💳 **Fee Information:** Provides a section for university fee-related resources.
* 🎓 **Scholarships:** Includes scholarship-related information.
* 🤝 **Clubs & Events:** Provides information about student activities.

*Features should be retained only if they are implemented in the project.*

## 🧠 Data Structures & Algorithms

### Trie

A Trie data structure supports prefix-based searching through notice titles.

### Stack

A Stack follows the Last-In, First-Out (LIFO) principle and can be used to maintain recently viewed notices.
